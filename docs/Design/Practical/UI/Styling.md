# Styling the (web) UI

The web frontend is the reference implementation for all Lumina's UI.

Lumina is not minimalistic. It follows web design trends from decades ago with that approach, but also prefers a clean and modern design. This is why coloured elements are very important, but it also allows us to implement features considered old-school nowadays.

Previously, Lumina used [DaisyUI](https://daisyui.com/) and [TailwindCSS](https://tailwindcss.com/), in iteration 3, the aim is to style as much as possible through [OatUI](https://oat.ink/)'s semantic styling, but with [[Styling/Tailwind usage|modifications done using Tailwind CSS]].

See also: [Theme](Styling/Theme.md).
