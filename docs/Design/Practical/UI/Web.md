# Web
The web frontend is the face of an instance, it is considered part of the instance itself, while also being an application of it's own. It's sometimes referred to as "client", but in [iteration 3](../../../README.md), it is actually embedded within the server.

As it is the face of the application, it is also the reference implementation of the UI.
