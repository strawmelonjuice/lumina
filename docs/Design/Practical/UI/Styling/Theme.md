# Lumina Theme Design Specification

## The fonts in Lumina

We use typography to subtly separate system controls, brand identity, and content generated by our users. It keeps things looking distinct but cohesive:

*   **Main Font (`--font-sans`)**: We use **Vend Sans** as the main font.
*   **Mono Font (`--font-mono`)**: **DM Mono** is used for code blocks, scripts, data, etc.
*   **Lumina 'logo' font (`--font-logo`)**: **Gantari** is reserved entirely for the "Lumina" logo header to separate it a bit from the rest and keep it reliably the same everywhere.
*   **User-generated (`--font-content`)**: We intentionally use **Elms Sans** for user-generated text fields and input areas. This visually separates what we put there, from what a user typed.
*   **Menu font (`--font-menuitems`)**: **Josefin Sans** goes on our menus, sidebars, and header tabs.

## The colours in Lumina

Instead of maintaining a messy list of class overrides for dark mode, we use native CSS `light-dark()` mapping. Here is exactly how our palette fits into the layout blocks:

| Design Space         | CSS variable           | Light Mode Target (OKLCH) | Dark Mode Target (OKLCH) | Where to use it                                      |
| :------------------- | :--------------------- | :------------------------ | :----------------------- | :--------------------------------------------------- |
| **Canvas backdrop**  | `--background`         | `0.9516 0.0312 70.53`     | `14% 0.02 156.743`       | Main app background canvas.                          |
| **Body text**        | `--foreground`         | `51% 0.096 186.391`       | `85% 0.08 186.391`       | Standard text readable against the canvas.           |
| **Component block**  | `--card`               | `0.8622 0.0447 122.78`    | `26.9% 0 5`              | Embedded sections, cards, and text inputs.           |
| **Component text**   | `--card-foreground`    | `51% 0.096 186.391`       | `85% 0.08 186.391`       | Labels and descriptive paragraphs inside cards.      |
| **Layout panels**    | `--faint`              | `94% 0.028 342.258`       | `25% 0.02 342.258`       | Sunken structural accent blocks or sidewells.        |
| **Primary action**   | `--primary`            | `87% 0.15 154.449`        | `50% 0.15 154.449`       | Main action buttons, active states, and focus rings. |
| **Primary text**     | `--primary-foreground` | `30% 0.056 229.695`       | `88% 0.09 229.695`       | Text inside primary components for perfect contrast. |
| **Secondary action** | `--secondary`          | `51% 0.253 323.949`       | `38% 0.23 323.949`       | Alternative buttons and sub-navigation links.        |
| **Accent highlight** | `--accent`             | `80% 0.114 19.571`        | `55% 0.12 19.571`        | Eye-catching callouts, tabs, and brand highlights.   |
| **Muted blocks**     | `--muted`              | `98% 0.003 247.858`       | `12% 0.01 247.858`       | Lower priority text or secondary header backdrops.   |

### System Feedback Colors
We use dedicated semantic pairs to deliver instantly recognizable status warnings, following [Oat UI](https://oat.ink/) practice:

*   **Info (`--info`)**: Blue hue for general alerts or neutral update popups.
*   **Success (`--success`)**: Crisp green hue for verified operations or successful inputs.
*   **Warning (`--warning`)**: Warm orange hue for non-breaking user errors or temporary status issues.
*   **Danger (`--danger`)**: High-impact red hue for breaking structural errors, critical system alerts, and delete triggers.
