# Tailwind usage within `Lumina:Peonies:itr3`

Tailwind is used in iteration 3, but sparingly. To keep it from colliding with OatUI's classes system, it's configured to only [respond to the `tw:` prefix](https://tailwindcss.com/docs/upgrade-guide#using-a-prefix). Use semantic (OatUI-styled) HTML when possible, only adjust it with Tailwind.
